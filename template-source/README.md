# Private M20 rendering inputs

`M20 Template Interior.pdf` is the unmodified, eight-page reference retained
from the user-supplied Mage templates. Its SHA256 is
`4c876e07b17f4a85877213d557b3f0236004bf6baa48d0bef708a68745e93df5`.

The repository owner explicitly authorized including this reference, its
required supplied fonts, and extracted decorations in this private repository
for the licensed STV workflow. This records the owner's assertion; licensing
has not been independently verified. Preserve the private distribution scope
and the embedded copyright/trademark notices. `fonts/NOTICES.txt` retains
available font notices, including the public DejaVu license texts. No license
text for Goudy/Abbess accompanied this retained input set beyond their embedded
notices; those fonts are not represented as freely redistributable.

Only the PDF and nine rendering faces are retained; unused InDesign/PSD inputs
are omitted. `assets/` contains prepared decorations extracted using the four
checked original-template extractors in `contrib/original-m20-layout/overrides/scripts/`.
Ordinary installation uses committed bytes and never needs to run extraction.
`bundle-manifest.json` records the exact binary input/decorative hashes and
canonical LF hashes of text notices/provenance.
